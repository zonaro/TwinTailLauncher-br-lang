O que é este pacote?

O Twintail Launcher é um launcher gratuito e de código aberto (Tauri + Rust + TypeScript) para gerenciar jogos de anime no PC — download, atualização, mods via XXMI, desbloqueio de FPS e mais. O site oficial é twintaillauncher.app.

Este repositório é a tradução comunitária para português do Brasil: o arquivo pt_BR.json baseado no en_US.json (branch stable), com termos técnicos preservados (Runner, Prefix, MangoHUD, Gamemode, XXMI…) e placeholders intactos ({install_name}, {speed}…).

Ficha rápida

  • Arquivo: pt_BR.json
  • Nome no app: Português (Brasil)
  • Código: pt_BR
  • Instaladores: install.sh e install.ps1
  • Desinstaladores: uninstall.sh e uninstall.ps1
  • Licença: mesma do upstream (GPL-3.0)
  • Afiliação: nenhuma — projeto da comunidade

Como instalar (1 minuto)

Opção 1 — automática recomendada

Rode no terminal. O script baixa o pt_BR.json, valida o JSON, localiza o Twintail Launcher (deb, Flatpak sistema/usuário, AUR, binário) e copia o arquivo para resources/locales — usando sudo só quando precisa.

curl -fsSL https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/install.sh | bash

Rode no PowerShell. O script baixa o pt_BR.json, valida o JSON, localiza o Twintail Launcher (registro do Windows, %LOCALAPPDATA%, Program Files) e copia o arquivo para resources\locales. Só pede elevação de administrador (UAC) quando a pasta exigir.

irm https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/install.ps1 | iex
Alternativas no Linux (wget / process substitution) 
wget -qO- https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/install.sh | bash

# ou
bash <(curl -fsSL https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/install.sh)
Alternativas no Windows (baixar o arquivo / Xbox Game Bar) 
# Baixar o script e rodar do arquivo (permite -ExecutionPolicy e flags)
irm https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/install.ps1 -OutFile install.ps1
.\install.ps1

# Se a execução de scripts estiver bloqueada, use o flag por processo:
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

O irm … | iex funciona mesmo com a política de execução restritiva, porque o iex não passa pelo bloqueio de arquivos.

Opção 2 — manual

  1. Baixe o arquivo: 
    curl -fsSL https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/pt_BR.json -o /tmp/pt_BR.json
  2. Encontre a pasta de locales: 
    find /usr /opt $HOME -name "en_US.json" 2>/dev/null | grep -i twintail
  3. Copie (troque <caminho> pelo resultado): 
    sudo cp /tmp/pt_BR.json <caminho>/pt_BR.json
sudo chmod 644 <caminho>/pt_BR.json
  4. Reinicie o launcher e siga o passo de trocar o idioma.
  1. Baixe o arquivo: 
    irm https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/pt_BR.json -OutFile pt_BR.json
  2. Encontre a pasta de locales (onde está o en_US.json): 
    Get-ChildItem "$env:LOCALAPPDATA","$env:ProgramFiles" -Filter en_US.json -Recurse -Depth 4 -ErrorAction SilentlyContinue
  3. Copie (troque <caminho> pelo resultado): 
    Copy-Item .\pt_BR.json "<caminho>\pt_BR.json" -Force
  4. Reinicie o launcher e siga o passo de trocar o idioma.

Como trocar o idioma para português

  1. Feche totalmente o launcher (bandeja do sistema → Sair/Quit).
  2. Reabra o Twintail Launcher.
  3. Abra Launcher Settings → General → Application language.
  4. Selecione “Português (Brasil)”.
  5. Reinicie se o app pedir. Pronto: você verá “Configurações do Launcher”.
Não apareceu “Português (Brasil)” na lista?

Verifique se o arquivo foi copiado para o lugar certo:

ls -lh /usr/lib/twintaillauncher/resources/locales/pt_BR.json
ls -lh /var/lib/flatpak/app/app.twintaillauncher.ttl/current/active/files/lib/twintaillauncher/resources/locales/pt_BR.json
find /usr /opt /var/lib/flatpak $HOME/.local/share/flatpak -name "pt_BR.json" -path "*twintail*resources/locales*" 2>/dev/null

Se o find não retornar nada, rode o instalador de novo e confira a mensagem de erro — geralmente é caminho do Flatpak usuário vs. sistema.

Verifique se o arquivo foi copiado para o lugar certo:

Get-Item "$env:LOCALAPPDATA\twintaillauncher\resources\locales\pt_BR.json" | Format-List Name,Length
Get-ChildItem "$env:LOCALAPPDATA" -Filter pt_BR.json -Recurse -Depth 4 -ErrorAction SilentlyContinue

Rode o instalador de novo e confira a mensagem de erro — o script lista todas as pastas que tentou.

Como desinstalar

Os desinstaladores removem apenas o arquivo pt_BR.json das pastas de locales que detectarem. Nada mais do launcher é tocado.

Automático recomendado

curl -fsSL https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/uninstall.sh | bash
irm https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/uninstall.ps1 | iex
Quer ver o que será apagado antes? Baixe o script e use o modo de simulação — nada é removido.
Simulação (Linux) 
curl -fsSL https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/uninstall.sh -o uninstall.sh
bash uninstall.sh --dry-run
Simulação (Windows) 
irm https://raw.githubusercontent.com/zonaro/TwinTailLauncher-br-lang/main/uninstall.ps1 -OutFile uninstall.ps1
.\uninstall.ps1 -DryRun

Manual

# Encontrar
find /usr /opt /var/lib/flatpak $HOME/.local/share/flatpak -name "pt_BR.json" -path "*resources/locales*" 2>/dev/null

# Remover
sudo rm /usr/lib/twintaillauncher/resources/locales/pt_BR.json
# Encontrar
Get-ChildItem "$env:LOCALAPPDATA","$env:ProgramFiles" -Filter pt_BR.json -Recurse -Depth 4 -ErrorAction SilentlyContinue

# Remover (use o PowerShell como administrador se der erro de acesso)
Remove-Item "$env:LOCALAPPDATA\twintaillauncher\resources\locales\pt_BR.json" -Force

Depois de remover, feche e reabra o launcher e escolha outro idioma em Launcher Settings → General → Application language.

Perguntas frequentes

Preciso reinstalar a cada atualização do launcher?

Na maioria das vezes, não — o arquivo fica na pasta de locales. Mas atualizações via Flatpak/AUR ou o instalador do Windows podem sobrescrever a pasta. Se o português sumir após atualizar, rode o instalador de novo.

Funciona no Windows?

Sim, com instalador próprio em PowerShell. Use irm … install.ps1 | iex — o script detecta a instalação pelo registro do Windows e por %LOCALAPPDATA%\twintaillauncher, e só solicita elevação de administrador quando a pasta de destino não permite escrita. Funciona no Windows PowerShell 5.1 e no PowerShell 7+.

Vou receber um aviso do Windows ao rodar?

Só o prompt do UAC, e apenas se a instalação estiver em Program Files (a instalação padrão é por usuário, em %LOCALAPPDATA%, e não pede nada). O irm … | iex não é bloqueado pela política de execução do PowerShell.

É seguro? Vou ser banido?

O pacote só adiciona um arquivo de tradução — não modifica o jogo nem o comportamento do launcher. Sobre bans e Proton no Linux, valem as mesmas ressalvas do FAQ oficial: decisões são das desenvolvedoras dos jogos.

Como desinstalar?

Use os desinstaladores — eles removem só o pt_BR.json. Veja a seção Como desinstalar para os comandos e para o modo de simulação.

Encontrei um erro de tradução. Como ajudar?

Abra uma issue ou mande um PR com a correção no pt_BR.json. Toda ajuda é bem-vinda!
